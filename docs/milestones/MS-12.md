## 3. Kriteria Penerimaan (Acceptance Criteria)

- [ ] **AC-12.1** Setiap laporan hanya dapat dibuka oleh peran yang berhak sesuai matriks hak akses dan menjawab `403 forbidden` bagi peran yang tidak berhak.
- [ ] **AC-12.2** Store Manager yang memanipulasi parameter `outlet_id` atau `organization_id` di URL tetap hanya mendapatkan data outlet tugasnya sendiri (atau `404 not_found`). Store Manager multi-outlet (Sari) dapat beralih antara Jodi Dago & Jodi Gubeng di bawah Seduhan Kopi Jodi.
- [ ] **AC-12.3** Laporan Laba Kotor Outlet (R-16) mendukung filter organisasi (Seduhan Kopi Jodi, Kaveloka, Plaga) dan konsolidasi, menampilkan lencana Estimasi yang sama persis dengan kartu `gross_profit`; telusur menuju daftar nota tertunda.
- [ ] **AC-12.4** Angka total di Ringkasan Penjualan (R-20) identik dengan kartu `sales_summary`; angka R-05 identik dengan `stock_issues`; angka R-08 identik dengan `true_up_pending`.
- [ ] **AC-12.5** Isi unduhan CSV dan XLSX sama persis dengan baris data tabel pada filter yang sama; keterangan filter aktif ikut tercetak.
- [ ] **AC-12.6** Mengirim `POST /pos/sales` dua kali dengan `Idempotency-Key` sama hanya membuat satu transaksi dan satu set mutasi stok.
- [ ] **AC-12.7** Penjualan produk dengan opsi modifier mengurangi stok bahan sesuai formula efek resep.
- [ ] **AC-12.8** Laporan dengan 50.000 baris data tetap responsif (paginasi server tanpa memuat seluruh baris ke memori browser).
- [ ] **AC-12.10** R-24 (Daily Close) menampilkan ringkasan EOD yang konsisten dengan data di `PG-eod-summary` dan kartu `outlet_ops_status`.
- [ ] **AC-12.11** R-25 (Loyalitas) menampilkan data read-only dari sumber CRM/POS; jika integrasi belum tersambung, menampilkan halaman "Data belum tersedia" (bukan error).
- [ ] **AC-12.12** R-26 (Kehadiran) menampilkan halaman "Integrasi belum tersambung" dengan informasi cara mengaktifkan.
- [ ] **AC-12.9** Preset filter tersimpan secara privat per pengguna dan tidak terlihat oleh pengguna lain.
