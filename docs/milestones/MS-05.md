## 1. Tujuan Milestone
Membangun satu mesin evaluasi persetujuan terpusat (*approval engine*) untuk seluruh jenis dokumen sensitif di sistem, lengkap dengan kotak masuk terpadu (*unified inbox*), alur penolakan beralasan, penanganan step-up auth, dan pengujian aturan.

## 2. Checklist Tugas (Tasks)

### Sub-Fase MS-05A: Mesin Evaluasi Aturan Persetujuan
- [ ] **T-05.1 Skema Kontrak & Service Persetujuan**
  - [ ] Endpoint: `GET/POST /approval-requests`, `POST /approval-requests/{id}/actions/approve|reject|cancel`.
  - [ ] Endpoint aturan: `GET/POST /approval-rules`, `POST /approval-rules/evaluate`.
  - [ ] Endpoint step-up: `POST /auth/step-up`.
- [ ] **T-05.2 Fungsi Domain Evaluasi Persetujuan (§6.7 & §6.8)**
  - [ ] Evaluasi dokumen terhadap aturan aktif: memilih tingkat tertinggi.
  - [ ] Validasi invariant: **Pembuat tidak dapat menyetujui dokumennya sendiri** (`403 forbidden`, `code: self_approval`).
  - [ ] Mode persetujuan: `any_of` (cukup satu penyetuju) vs `all_of` (seluruh peran wajib setuju).
  - [ ] Optimistic locking: jika dokumen sumber berubah versi, persetujuan ditolak `409 conflict`.
  - [ ] Alasan penolakan wajib diisi saat menolak.
- [ ] **T-05.7 Editor Aturan Persetujuan (`PG-set-approval-rules`)**
  - [ ] Tabel tingkat, ambang batas, penyetuju, mode, konfigurasi step-up, masa berlaku.
  - [ ] **Panel Uji Aturan Interaktif**: Masukkan jenis dokumen, outlet, dan nominal → tampil tingkat persetujuan dan peran penyetuju.

### Sub-Fase MS-05B: Unified Inbox & Hooks Dokumen
- [ ] **T-05.3 Handler Mock & Transisi Dokumen Otomatis**
  - [ ] Pembuatan permintaan persetujuan otomatis saat dokumen diajukan (PO luar, kas kecil tier 2/3, selisih opname, usulan menu).
  - [ ] Memancarkan event `ApprovalDecided` untuk memperbarui status dokumen sumber secara otomatis.

## 3. Kriteria Penerimaan (Acceptance Criteria)

- [ ] **AC-05.1** Panel uji aturan mereproduksi hasil skenario tabel §6.8 secara presisi.
- [ ] **AC-05.2** Budi tidak dapat menyetujui dokumen yang dibuatnya sendiri; Rina dapat menyetujui dokumen tingkat 3.
- [ ] **AC-05.3** Pada mode `any_of`, persetujuan oleh Maya menyelesaikan permintaan tingkat 2 tanpa memerlukan persetujuan Rina.
- [ ] **AC-05.4** Menolak permohonan tanpa mengisi alasan ditolak oleh validasi sistem.
- [ ] **AC-05.5** Menyetujui dokumen yang versinya telah berubah menghasilkan galat `409 conflict`.
- [ ] **AC-05.6** Angka lencana "Persetujuan" selalu sama persis dengan jumlah dokumen di tab **Menunggu Saya**.
- [ ] **AC-05.7** Menyetujui dokumen menggerakkan status dokumen sumber (PO `approved`, opname `posted`, usulan menu `approved`).
- [ ] **AC-05.8** Aksi yang membutuhkan step-up ditolak tanpa token valid; berhasil saat password benar dimasukkan.
