## 1. Tujuan Milestone
Membangun manajemen stok per outlet berbasis ledger riwayat mutasi (*append-only ledger*), penghitungan rata-rata biaya bergerak (*moving average*), opname fisik beserta alur persetujuan selisih, pencatatan waste, produksi bahan olahan, dan transfer stok antar-outlet.

## 2. Checklist Tugas (Tasks)

### Sub-Fase MS-06A: Append-Only Stock Ledger & Moving Average
- [ ] **T-06.1 Skema Kontrak & Service Inventaris**
  - [ ] Endpoint: `GET /inventory/stock`, `GET /inventory/movements`, `GET /inventory/alerts`.
- [ ] **T-06.2 Fungsi Domain Proyeksi Stok & Moving Average (§6.5 & §6.10)**
  - [ ] Ledger append-only: `PUT`/`DELETE` dilarang (`405 Method Not Allowed`).
  - [ ] Formula moving average (§6.5): `avg_baru = (qty_lama × avg_lama + qty_masuk × biaya_masuk) / (qty_lama + qty_masuk)`. Vektor uji: 10 L @ 18.000 + 20 L @ 21.000 = **20.000**.
  - [ ] Stok negatif diperbolehkan dengan penanda peringatan.
  - [ ] Estimasi sisa hari dari rata-rata pemakaian 14 hari (§6.10).
- [ ] **T-06.3 Subscriber Event Mutasi Stok**
  - [ ] Handler event `GoodsReceived` (penambahan stok) dan `SaleIngested` (pengurangan stok sesuai resep).
- [ ] **T-06.4 Halaman Stok Bahan (`PG-inv-stock`)**
  - [ ] Tabel stok per outlet × bahan, filter kategori, badge status stok, panel rincian (riwayat mutasi, grafik saldo, penanda biaya `provisional`).
- [ ] **T-06.5 Kartu Stok / Riwayat Pergerakan (`PG-inv-movements`)**
  - [ ] Filter jenis transaksi, rentang tanggal, referensi dokumen, dan tombol ekspor.

### Sub-Fase MS-06B: Stock Opname, Selisih & Pencatatan Waste
- [ ] **T-06.6 Alur Stock Opname (`PG-inv-counts`)**
  - [ ] Buat lembar hitung fisik → Input hitungan fisik + catatan/foto → Kirim → Hitung selisih.
  - [ ] Evaluasi ambang selisih: jika selisih > Rp200.000 atau > 5% → Masuk inbox MS-05 (`pending_approval`). Jika disetujui → Posting adjustment otomatis.
- [ ] **T-06.7 Jadwal Opname Teratur (`PG-inv-count-schedule`)**
  - [ ] Pengaturan jadwal (harian/mingguan/bulanan) dan pengingat opname terlambat di dashboard SM.
- [ ] **T-06.8 Pencatatan Waste Bahan (`PG-inv-waste`)**

- [ ] **T-06.11 Koreksi Manual Stok Khusus Admin**
